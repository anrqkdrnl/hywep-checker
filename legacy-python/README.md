# 예전 터미널 버전 (v1, Python + Playwright)

v2부터는 **Mac 앱 하나로 모든 기능**이 동작해요. Python과 터미널이 없어도 돼요. 새로 쓰는 분은 저장소 루트의 README를 따라 앱을 설치하세요.

이 폴더는 기록용으로 남겨 둔 예전 버전이에요.

- `install.sh`: `~/.<이름>_check/`에 스크립트와 venv를 설치하고, 키체인 입력과 launchd 등록을 해요.
- v2 앱을 쓰기 시작했다면 앱 설정의 **예전 버전 자동 실행 끄기**로 이 버전의 자동 실행을 꺼 주세요. 그대로 두면 아침 팝업이 두 번 떠요.
